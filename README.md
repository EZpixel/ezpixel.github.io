# ezpixel.github.io

The EZpixel studio website, served by GitHub Pages at https://ezpixel.github.io.

A single static page (`index.html`) with no build step. Images live in `assets/`
and are copied from the Blunday repo (`resources/icon`, `resources/store`,
`resources/achievements/play`, `resources/leaderboard`).

Blunday itself (the browser version and its privacy policy) is published
separately from the Blunday repo at https://ezpixel.github.io/Blunday/.
